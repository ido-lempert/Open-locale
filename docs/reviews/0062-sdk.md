# 0062 - JavaScript SDK (core workflow)

PLAN names SDKs under automation and delivery. This slice adds
`libs/sdk` (`@open-locale/sdk`): a zero-dependency ESM client for the REST
API v1, node >=20, no build step (plain .mjs + hand-written .d.ts), matching
the CLI's zero-dependency posture.

## Scope

- `createClient({ url, token, fetchImpl? })` with X-Api-Key auth.
- Wrapped surface: projects.list/get, keys.list/create, translations.get
  (flat export map)/put, io.importEntries (with dryRun), io.exportText for
  any interchange format. Everything carries the optional `branch` scope the
  API supports.
- NOT full API parity: webhooks, tasks, groups, reports, settings and the
  rest are reachable through the exposed low-level `request(path, opts)`
  escape hatch, not dedicated methods. No claim of complete coverage.
- Errors throw `OpenLocaleError` carrying HTTP status and path.
- The package is private (not published to any registry); consumers import
  it from the repo.

## Boundaries verified

scripts/sdk-test.mjs runs the SDK against a real PostgreSQL + real API:
constructor guards, list/create/search, put + flat get roundtrip, import
with summary counts, dry-run preview leaving data unchanged, PO export body,
branch-scoped import/export, 404 and 401 error shape (status + path).
